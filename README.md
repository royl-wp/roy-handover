# roy-handover

An encrypted document. A password is required to view it.

- **View:** https://royl-wp.github.io/roy-handover/
- **Access:** the password is issued directly to the intended recipients. It is not published here.

The contents are confidential. The page is encrypted client-side with
[StatiCrypt](https://github.com/robinmoisson/staticrypt) — this repository holds only the
encrypted payload, and nothing in it is readable without the password.
